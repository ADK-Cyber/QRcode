# QR Code Generator

A minimal black-and-white QR code generator built with HTML, CSS and vanilla JavaScript.

Enter a URL or text, generate a scannable QR code, download it as a PNG, or clear it and start over.

## How to run

Download the files and open `index.html` in your browser. No installation needed.

## Files

- `index.html`: page structure
- `style.css`: styling
- `script.js`: functionality
